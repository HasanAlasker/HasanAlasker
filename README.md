## 💡 Philosophy

I don't build projects to collect technologies, I build them to answer questions:

* **Realtime State:** How do multiple users edit the same document concurrently without conflicts?
* **Resilience:** How do mobile applications maintain functionality over unreliable networks?
* **Maintainability:** How should frontend architecture evolve as codebases scale?
* **Simplicity:** How can software remain simple while solving complex underlying problems?

Every repository here is an experiment centered around one of those questions.

## 🛠️ Selected Work

### 🚗 Servio
A production-focused vehicle maintenance platform built with React Native and Node.js. Designed around real-world usage featuring dynamic service scheduling, automated reminders, FCM notifications, and multi-vehicle tracking.

> **Engineering Challenge**  
> Designing a maintainable frontend architecture while orchestrating mobile state, backend micro-tasks, cron jobs, and push notifications.

<br>

### 📝 Collaborative Markdown Editor
A realtime collaborative workspace engineered to explore distributed systems patterns. Features concurrent editing, local-first state, conflict-free synchronization, and automatic recovery upon reconnection.

> **Engineering Challenge**  
> Implementing CRDT-based collaboration models to achieve true convergence without relying on naive document replacement.
